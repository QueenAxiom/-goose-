# Axiom Enterprises

Repo for Axiom Enterprises — Alan "Goose" Gooding's digital business operations.

## Structure

- `sites/` — code/config for the three Axiom Empire sites
  - `empoweredathome/` — EmpoweredAtHome.com (AI/robotics/smart home marketplace)
  - `everythinginternet/` — EverythingInternet.ca (Canadian tech directory, main hub)
  - `schmucksdebate/` — SchmucksDebate.com (advisory/game/career transformation platform)
- `automation/` — content pipeline, N8N workflows, agent scripts
- `docs/` — reference docs, build plans, SOPs
