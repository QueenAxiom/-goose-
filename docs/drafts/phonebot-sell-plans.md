# PhoneBot — Sell Plans

© Axiom Enterprises

## Price tiers

### Plan 1 — Free

Price: Free plans. You buy the parts (~$595).

What's included: parts list, CAD/STL files for the base build, build guide, wiring diagram, software.

What's NOT included: parts, phone, arms design files.

### Plan 2 — Kit — $899

Price: $899.

What's included: every part in one box — all 17 servos, brackets, boards, battery, cables, arm hardware — plus the full build guide, wiring diagram, software.

What's NOT included: phone, assembly.

### Plan 3 — Built — $1,500

Price: $1,500.

What's included: fully assembled robot, tested, walking. 17 joints, gesture arms, dressed.

What's NOT included: phone — you supply an old Android phone (it's the brain).

All tiers: flat floors only, gesture arms only — no meaningful lifting.

## Hand sensors

No, in any tier. The arms are gesture-only — wave, point, gesture. No touch sensors in the hands. Keeps the cost down and the build simple. A sensor-hand upgrade is a possible future option if demand shows up.

## Open-source vs proprietary

Base robot: open-source — UCLA RoMeLa's PhoneBot (arXiv:2610.08737), per its license, with attribution.

Gesture arms: proprietary Axiom design. The arm design files are NOT in the free plans — arms come as parts in the Kit and Built tiers. The arms are our edge.
